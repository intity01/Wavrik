# Grounded Visual Directions for MediaDownloaderPRO

## Cultural Context
Windows 10/11 users who need a premium productivity tool for single-download focus. They work with modern desktop applications daily and expect clean, efficient interfaces with subtle polish.

## Seven Concrete Visual Systems (ordered by resonance)

1. **Windows 11 Fluent Design System** - Native Windows 11 apps (Settings, File Explorer, Microsoft Store) with acrylic materials, subtle depth, rounded corners, and smooth animations. This is the target platform's visual language users expect.

2. **Modern Browser UI** - Chrome/Edge DevTools, Arc Browser with their dark themes, tab systems, sidebar navigation, and clean content areas. Users spend hours in browsers and this pattern is deeply familiar.

3. **Contemporary Code Editors** - VS Code, Sublime Text with their minimalist dark themes, command palettes, tree views, and status bars. Power users recognize this efficient, information-dense layout.

4. **Modern Task Management** - Notion, Linear, Todoist with their clean surfaces, subtle borders, good typography, and progressive disclosure. These represent modern productivity expectations.

5. **Premium Media Applications** - Spotify Desktop, Plex with their dark themes, card-based layouts, smooth transitions, and focus on content hierarchy. Media users expect this polish.

6. **System Utilities & Monitors** - Task Manager, Resource Monitor, clean system tools with their tabbed interfaces, data visualization, and functional density. Utility tools share this language.

7. **Design & Creative Tools** - Figma, Adobe Creative Cloud with their dark interfaces, property panels, canvas areas, and sophisticated controls. Users who need visual polish recognize this quality level.
