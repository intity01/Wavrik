# Product

## Register

product

## Users

Windows users who need to save public audio, video, or playlists while working in other desktop applications. Their primary task is to turn a valid link into a correctly formatted file in a known folder without learning yt-dlp terminology.

## Product Purpose

Media Downloader PRO provides a dependable desktop flow: paste a link, choose output once, download, and open the result. Success means the user can understand the queue, output format, destination, and download state without using a terminal.

## Brand Personality

Calm, direct, trustworthy. The product explains operational state plainly and avoids marketing language, decorative celebration, and jargon.

## Anti-references

Avoid trendy dashboard decoration, glassmorphism, gradients, glow, fake metrics, emoji controls, excessive rounding, and unfamiliar controls invented for visual novelty.

## Design Principles

1. Keep the download decision and its consequences visible in one workspace.
2. Prefer familiar desktop controls and explicit action labels over novelty.
3. Show progress, errors, and trust boundaries in the place where users can act.
4. Preserve active-job settings so a visible choice remains a reliable promise.
5. Use visual restraint to keep attention on the current task.

## Accessibility & Inclusion

Target WCAG 2.1 AA contrast, keyboard-operable controls, visible focus, text labels for state, and reduced reliance on color alone. The app minimum is 760×600 and each screen must remain usable with scrolling at that size.
