# Global Loop Memory
Shared across all loops in this project.
## Learnings
- [full-codebase-audit, task 1] Catching generic OSError in atomic file stores causes transient OS file locks (especially Windows SharingViolation) to be misinterpreted as data corruption, falsely quarantining valid application state to .corrupt.
- [full-codebase-audit, task 2] Trusting remote server Content-Disposition headers for downloaded file extensions paired with desktop shell openers (os.startfile) creates an arbitrary code execution (RCE) vector upon opening files; client preset extension whitelists must strictly govern output file paths.
- [full-codebase-audit, task 3] Qt QPixmap paint devices must never be created or loaded in background worker threads or QThreadPool; background workers must process raw bytes or QImage and convert to QPixmap on the GUI main thread to prevent thread hazards and crashes.
- [full-codebase-audit, task 3] Connecting real-time text input signals directly to composite widget list reconstruction without debouncing causes severe UI freezes when child widgets execute synchronous filesystem calls (e.g. Path.is_file) during instantiation.
- [remediate-audit-fixes, task 1] Desktop file openers (os.startfile/xdg-open) must enforce a hardcoded executable and script extension blacklist (BLOCKED_EXTENSIONS) before launching paths to prevent accidental shell execution of downloaded files.
- [remediate-audit-fixes, task 2] In background worker retry/backoff loops, using threading.Event.wait(timeout=delay) instead of time.sleep(delay) allows workers to cancel immediately (< 50ms) rather than blocking until the sleep duration finishes.
- [remediate-audit-fixes, task 3] Subprocess invocations of streaming CLI tools like FFmpeg require network input timeouts (-rw_timeout in microseconds), process execution timeouts (communicate(timeout=N)), and CREATE_NO_WINDOW on Windows to prevent permanent process hangs and disruptive command prompt popups.
- [remediate-audit-fixes, task 4] On Windows test environments where temp folder locks create PermissionError WinError 5 on pytest tmp_path, passing `--basetemp=.pytest-temp-verify` redirects temp test folders reliably to the project directory.
- [arch-rules-hardening, task 2] Refactoring high-arity function signatures into frozen domain dataclasses paired with private argument-unpacking adapters enforces strict parameter limits (<= 6) while maintaining 100% backward compatibility across callers and existing test suites.
- [arch-rules-hardening, task 4] When wrapping high-arity functions into dataclasses with legacy unpacking adapters, defaulting the primary parameter to None (e.g. param: Dataclass | str | None = None) is necessary to prevent TypeErrors when callers pass the primary identifier via keyword argument.
- [cross-platform-hardening, task 1] PyInstaller 6 onedir layout stores collected binaries and dependencies under '_internal' while onefile extracts to sys._MEIPASS; robust asset discovery must probe application_root, resource_root (sys._MEIPASS), and application_root / '_internal' before falling back to system PATH.
- [cross-platform-hardening, task 4] Cross-platform OS-dependent logic (Windows vs Darwin vs Linux binary resolution and desktop notification calls) can be 100% regression-tested on a single host OS runner by monkeypatching sys.platform and subprocess/shutil boundaries in pytest without multi-OS CI virtualization.
