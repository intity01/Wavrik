# Loop Memory
Updated continuously by all agents as they discover things.
## Learnings
- [remediate-audit-fixes, task 1-security] Desktop file openers (os.startfile/xdg-open) must enforce a hardcoded executable and script extension blacklist (BLOCKED_EXTENSIONS) before launching paths to prevent accidental shell execution of downloaded files.
- [remediate-audit-fixes, task 1-path-sanitization] Windows path sanitization must check filename stems against reserved DOS device names (CON, PRN, AUX, NUL, COM1-9, LPT1-9) and prepend an underscore to prevent Win32 device namespace collision errors.
- [remediate-audit-fixes, task 1-persistence] Atomic JSON stores must retry bounded transient OSErrors (lock collisions) rather than immediately quarantining files to .corrupt, which should be reserved strictly for JSONDecodeError or UnicodeDecodeError.
- [remediate-audit-fixes, task 2-thread-safety] Qt GUI components must handle `QImage` offloaded from background workers (e.g. `ThumbnailWorker`) and convert to `QPixmap` on the main GUI thread via `QPixmap.fromImage()` to prevent cross-thread paint device violations and crashes.
- [remediate-audit-fixes, task 2-ui-performance] Unconditional `style().unpolish()` and `style().polish()` calls on status labels cause heavy stylesheet re-computations and UI thrashing; guarding with `changed = self._state != state` eliminates style re-evaluations during active download progress updates.
- [remediate-audit-fixes, task 2-concurrency] Replacing `time.sleep()` in retry/backoff loops with `owner._cancel.wait(timeout=delay)` allows instant cancellation (< 50ms) instead of blocking for seconds during backoff.
- [remediate-audit-fixes, task 2-signal-throttling] Throttling progress signal emissions to <= 10 Hz (`time.monotonic()` interval >= 0.1s) with guaranteed emissions on first update and at >= 100.0% completion keeps UI responsiveness high and prevents Qt event-loop saturation.
- [remediate-audit-fixes, task 3-ui-responsiveness] Moving `Path.is_file()` checks out of composite card initializers into user-action callbacks combined with a 250ms single-shot `QTimer` search debounce and a 50-item initial pagination cap prevents event-loop stalls when navigating or searching history.
- [remediate-audit-fixes, task 3-subprocess-hardening] Subprocess wrappers invoking external tools like FFmpeg require input network timeouts (`-rw_timeout 15000000`), execution timeouts (`communicate(timeout=300)`), and `CREATE_NO_WINDOW` flags on Windows to prevent silent process hangs and console popups.
- [remediate-audit-fixes, task 3-dialog-safety] Native and Qt file dialog helpers must return `None` on cancellation, and calling components must early-return on empty paths to avoid clearing user configurations or flashing spurious parsing error banners.
- [remediate-audit-fixes, task 4-testing] On Windows systems where transient locks cause PermissionError (WinError 5) on the default Temp directory for pytest tmp_path, passing `--basetemp=.pytest-temp-verify` cleanly isolates temporary fixtures to the local workspace.
- [remediate-audit-fixes, task 4-verification] In Qt desktop applications, isolating pure domain, storage, and worker logic allows complete headless regression test execution (50/50 tests passing) without requiring GUI display servers or pytest-qt plugins.
